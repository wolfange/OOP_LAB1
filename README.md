# Лабораторная работа №1

### Вариант 20. Динамическая квадратная матрица `int**`.

#### Что умеет программа

- создать квадратную матрицу
- заполнить матрицу одним значением
- вывести матрицу
- проверить симметричность
- вычислить след матрицы

Матрица симметрична, если `matrix[i][j] == matrix[j][i]` для всех элементов.
След равен сумме элементов главной диагонали.

## Сборка

Из корня проекта:

```bash
cmake -B build
cmake --build build
```

## Запуск

```bash
./build/lab1_main
```
